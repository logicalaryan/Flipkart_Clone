## ✨ Features

- 🛍️ **Product Listing** – Browse products with clean card-based UI.
- 🔍 **Search** – Quickly find products with search functionality.
- 🧺 **Cart Management** – Add, remove, and update product quantities.
- 🔐 **Authentication** – User login/signup flow.

## ⚙️ Installation & Setup

```bash
# 1) Clone the repository
git clone https://github.com/logicalaryan/Flipkart_Clone.git

# 2) Move into the project
cd Flipkart_Clone

# 3) Install dependencies
npm --prefix client install
npm --prefix server install

# 4) Start backend server
npm --prefix server start

# 5) Start frontend app (new terminal)
npm --prefix client start
```
